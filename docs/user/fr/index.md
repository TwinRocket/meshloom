Meshloom relie une radio MeshCore à un navigateur. La radio parle au mesh, Meshloom garde l’historique et affiche tout dans un onglet. Cette partie part de zéro : elle explique ce que fait chaque morceau, comment installer le serveur sur une machine Linux ou une [image Raspberry Pi](/docs/rpi/), et comment envoyer un premier message.

Les pages se lisent dans l’ordre, mais rien n’oblige à tout lire. Si Meshloom tourne déjà et qu’il ne manque qu’un réglage, la section [Aller plus loin](/docs/deep/) reprend les transports, Docker, Home Assistant, Community, les variables d’environnement et le dépannage.
