Meshloom connects a MeshCore radio to a browser. The radio talks to the mesh, Meshloom keeps the history, and the interface shows it all in a tab. This section starts from zero: what each part does, how to install the server on a Linux machine or a [Raspberry Pi image](/en/docs/rpi/), and how to send a first message.

The pages are arranged in order, but you do not have to read everything. If Meshloom is already running and you only need one setting, [Go deeper](/en/docs/deep/) covers transports, Docker, Home Assistant, Community, environment variables, and troubleshooting.
